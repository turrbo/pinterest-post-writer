# Pinterest Post Writer

## Overview

This skill generates Pinterest content through an 8-phase cognitive simulation system that understands Pinterest's fundamental difference from other platforms: it's a **visual search engine** where content drives traffic for years, not a fleeting social feed. The system simulates the mental state of someone creating genuinely useful, saveable content rather than applying cosmetic rules.

## When to Use This Skill

- Creating pin titles and descriptions for blog posts, products, or resources
- Writing board titles and descriptions for content organization
- Drafting Idea Pin text overlays and narration
- Adapting existing content for Pinterest's search-first environment
- Optimizing underperforming pins for better discoverability
- Creating seasonal or evergreen pin content strategies

## The 8-Phase System

### Phase 1: Intake (Understanding the Pin's Purpose)

**Goal**: Understand what you're creating and WHO will search for it.

Pinterest is fundamentally about **search intent** and **save behavior**. Before writing anything, we need:

**Content Details:**
- What is this pin for? (blog post, product, tutorial, inspiration, list, etc.)
- What problem does it solve or aspiration does it fulfill?
- What would someone type into Pinterest search to find this?
- Is this evergreen (works year-round) or seasonal?
- What action do you want: saves, clicks, or both?

**Visual Context:**
- What's in the image/graphic? (Text must complement, not duplicate)
- Is this a product photo, infographic, lifestyle shot, or step-by-step?
- What text overlay is on the image itself?

**Target Audience:**
- Who is actively searching for this on Pinterest?
- What related topics are they exploring?
- What boards would they save this to?

**SEO & Keywords:**
- Primary keyword (what is this pin ABOUT?)
- Secondary keywords (related search terms)
- Long-tail variations people actually type

**Commercial Intent:**
- Is there a product/service/affiliate link involved?
- What's the business goal vs. value provided?

**Interactive Questions:**
```
1. What is this pin for? (URL if it's for a blog post/product)
2. Describe the image/visual
3. Who is searching for this content on Pinterest?
4. Primary keyword or search phrase?
5. Is this evergreen or seasonal? Any timing considerations?
6. Goal: maximize saves (broad reach) or clicks (traffic)?
7. Any products/services to mention naturally?
```

**Quick Mode**: "Just give me the post" with URL, keyword, and image description.

---

### Phase 2: Enter the State (Cognitive Mode Shift)

**Goal**: Simulate the mental state of someone creating genuinely useful Pinterest content, not writing marketing copy.

**The Pinterest Creator Mindset:**

This is NOT writing an Instagram caption or a tweet. This is creating **search-optimized, evergreen utility**.

**Mental state to simulate:**
- **Curator, not promoter**: You're helping someone discover exactly what they're looking for
- **Search-first thinking**: Every word is chosen for discoverability AND appeal
- **Visual complement**: The text supports the image, never competes with it
- **Save-worthy filter**: Would YOU save this to reference later?
- **Keyword naturalist**: SEO language that sounds human, not stuffed
- **Specificity over cleverness**: "Scandinavian living room ideas with Ikea furniture" beats "Amazing room inspo"
- **Aspiration + practical**: Pinterest users are planners and dreamers simultaneously
- **Evergreen patience**: This pin could drive traffic for 3 years

**What this feels like:**
- You're organizing your own board and writing the description you'd want to read when you rediscover it in 6 months
- You're answering the exact search query someone typed, not creating brand awareness
- You're being helpful first, clever never

**Common mental traps to avoid:**
- Trying to be "engaging" with questions or emoji (this isn't Instagram)
- Writing complete marketing sentences (Pinterest descriptions are naturally fragmented)
- Focusing on storytelling (Pinterest is action-oriented: save, plan, do)
- Burying the keyword for flow (SEO comes first, always)
- Making it about you/your brand (make it about THEIR need)

**State confirmation**: Before proceeding, mentally confirm:
- [ ] I know the exact search phrase this targets
- [ ] I'm thinking like someone saving content for later, not scrolling a feed
- [ ] I understand Pinterest is a tool, not a social platform
- [ ] I'm prepared to be specific, not clever

### Phase 3: Raw Draft (Unfiltered First Pass)

**Goal**: Generate initial Pinterest content in the authentic, slightly fragmented, keyword-rich style of real pins.

**Format options based on content type:**

**Standard Pin (most common):**
```
PIN TITLE (40-60 characters):
[Keyword-rich, specific, front-loaded with main search term]

PIN DESCRIPTION (200-500 characters):
[Expanded detail with secondary keywords, benefits, what's included, natural CTA]
```

**Idea Pin Text (multi-page):**
```
COVER TEXT:
[Hook - what they'll learn/get]

PAGE 2-5 TEXT:
[Specific, scannable steps/tips/points]

FINAL PAGE CTA:
[Natural next action]
```

**Board Description:**
```
BOARD TITLE (25-40 characters):
[Clear category + keyword]

BOARD DESCRIPTION (150-300 characters):
[What's saved here, who it's for, main keyword themes]
```

**Raw Draft Guidelines:**
- Lead with the primary keyword in the first 50 characters
- Be specific: names, numbers, categories, descriptors
- Use natural Pinterest language (slightly fragmented, not full sentences)
- Include 2-4 secondary keywords organically
- Add 1-2 relevant hashtags (Pinterest uses them differently than Instagram)
- End with a clear, non-pushy CTA if appropriate
- Avoid emojis (rarely used in successful pins)
- Avoid questions (people search for answers, not questions)

**Write the raw draft now** based on the intake info and mental state.

---

### Phase 4: Detection Scan (Claude-ism Analysis)

**Goal**: Identify AI-generated patterns that kill Pinterest content performance.

Pinterest text fails when it reads like generic marketing copy instead of useful search results. Run the raw draft through these detection filters:

**Generic Marketing Language:**
- [ ] "Discover the art of..." (nobody searches "discover the art of")
- [ ] "Unlock the secrets..." (too vague)
- [ ] "Transform your space/style/life" (overused, not specific)
- [ ] "Elevate your..." (formal, not search language)
- [ ] "Dive into..." (Instagram energy, not Pinterest utility)

**Over-Complete Sentences:**
- [ ] Full grammatically perfect sentences (Pinterest descriptions are punchier)
- [ ] Connector words used for flow (descriptions are naturally fragmented)
- [ ] Formal academic or business tone (too stiff)

**Missing Search Optimization:**
- [ ] Primary keyword not in first 50 characters
- [ ] Only one keyword used (needs 3-5 related terms)
- [ ] Generic adjectives instead of specific categories ("beautiful" vs "Scandinavian minimalist")
- [ ] No numbers, specifics, or qualifiers (vague = low performance)

**Wrong Platform Energy:**
- [ ] Questions to drive engagement (this isn't Instagram)
- [ ] Personal story or brand narrative (Pinterest is search-first, not story-first)
- [ ] "Tag someone who..." (wrong platform behavior)
- [ ] Casual conversational tone (Pinterest is reference material)
- [ ] Multiple emojis (rarely used in top pins)

**Promotion Red Flags:**
- [ ] Heavy brand focus in first 100 characters (bury the brand, lead with value)
- [ ] "Check out our..." (promotional frame)
- [ ] Product name before benefit/keyword
- [ ] "Limited time" or urgency language (contradicts evergreen nature)

**Detection Report**: List every Claude-ism or generic pattern found with specific examples from the draft.

---

### Phase 5: Banned Content Scan (Pinterest Compliance)

**Goal**: Ensure content complies with Pinterest's search algorithm, policies, and best practices.

Pinterest has unique content rules because it's a search engine with advertising policies:

**Algorithm Penalties:**
- [ ] Keyword stuffing (repeating same keyword >3 times unnaturally)
- [ ] Spam hashtags (>5 hashtags or irrelevant ones)
- [ ] Misleading descriptions (doesn't match image)
- [ ] Excessive caps or special characters
- [ ] Link text that says "click here" or "link in bio"

**Policy Violations:**
- [ ] Health claims or medical advice (very strict on Pinterest)
- [ ] Before/after weight loss content (banned)
- [ ] Tobacco, weapons, adult content mentions
- [ ] Dangerous DIY projects
- [ ] Counterfeit or trademark infringement

**Search Performance Killers:**
- [ ] No clear category signal (Pinterest needs to know where to show it)
- [ ] Mixed topics in one pin (confuses the algorithm)
- [ ] Clickbait language ("you won't believe...")
- [ ] Overly promotional (algorithm demotes sales-heavy content)

**Quality Standards:**
- [ ] Description under 100 characters (too short, underperforms)
- [ ] No call to action (leaves user hanging)
- [ ] Duplicate content from title to description (wasted space)
- [ ] Generic board name if creating board ("Ideas" or "Inspiration" = bad SEO)

**Compliance Report**: Flag any issues and explain why they hurt Pinterest performance.

---

### Phase 6: Targeted Revision (Surgical Fixes)

**Goal**: Fix detected issues while maintaining search optimization and authentic voice.

For each flagged issue from Phases 4-5, apply surgical revisions:

**Revision Strategy:**

1. **Replace generic with specific:**
   - Before: "Beautiful living room ideas"
   - After: "Scandinavian living room ideas with neutral color palette and Ikea furniture"

2. **Lead with keywords, not brand:**
   - Before: "Our favorite ways to style a coffee table"
   - After: "Coffee table styling ideas - 15 tray arrangements and centerpiece designs"

3. **Fragment for natural Pinterest style:**
   - Before: "This recipe will show you how to make delicious chocolate chip cookies that are perfect for any occasion."
   - After: "Easy chocolate chip cookies recipe. Soft, chewy, made with brown butter. Perfect for gift giving or holiday baking."

4. **Add specificity and numbers:**
   - Before: "Ways to organize your closet"
   - After: "12 small closet organization ideas under $50 - shelving, bins, and space-saving hacks"

5. **Embed secondary keywords naturally:**
   - Before: "Great outfit ideas"
   - After: "Business casual outfit ideas for women - workwear essentials, blazer styling, professional fashion"

6. **Adjust CTA for Pinterest behavior:**
   - Before: "Click to learn more!"
   - After: "Full tutorial on the blog with supply list and measurements"

**Produce the revised version** with annotations showing what changed and why.

### Phase 7: Adversarial Committee Review

**Goal**: Challenge the revised content through 7 different critical perspectives to catch remaining issues.

**Committee Members:**

**Tyler (Authenticity Guardian):**
- "Does this sound like a real person created it, or a marketing team?"
- "Would someone genuinely save this for later, or is it just content filler?"
- "Is the keyword usage natural or forced?"

**Marcus (Promo Skeptic):**
- "Is the value clear in the first 50 characters, or is this a disguised ad?"
- "If there's a product mention, does it feel helpful or salesy?"
- "Would this perform if the brand name was removed?"

**Kai (BS Detector):**
- "Is this actually specific and useful, or vague and generic?"
- "Do the keywords match what people ACTUALLY search on Pinterest?"
- "Is there any fluff that could be cut for tighter copy?"

**Jade (Pinterest Veteran, 500K followers):**
- "Is this optimized for saves or just clicks?"
- "Does the description add value beyond the title, or repeat it?"
- "Would this work as evergreen content or is it too timely?"
- "Is the format right for the content type?"

**Devon (Target Audience Member):**
- "Would I save this to a board? Which board?"
- "Does this answer my search query?"
- "Is it clear what I'm getting if I click?"

**Priya (Topic Expert):**
- "Is the information accurate and complete?"
- "Are the keywords the right level of specificity for the niche?"
- "Does this reflect current trends in this category?"

**Jamie (Pinterest Mod/Algorithm):**
- "Does this comply with Pinterest search best practices?"
- "Is it properly categorized with clear signals?"
- "Would this rank well for the target keyword?"
- "Any spam or manipulation signals?"

Each committee member provides:
1. **Score (1-10)**: How well does this meet their criteria?
2. **Critique**: Specific issues found
3. **Suggestions**: Concrete improvements (or approval if none needed)

[A/B test variations with different angles]

- [ ] Image includes text overlay with main keyword
- [ ] Alt text includes target keyword
